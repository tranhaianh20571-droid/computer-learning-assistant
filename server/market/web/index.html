Import → Bind → Teach

01 / Import

导入到本机

在卡片上点「导入」，选择直接导入到学伴；本地没运行时，也可以下载 ZIP 手动导入。

02 / Bind

账号绑定本机

第一次使用从桌面端发起绑定：注册、邮箱验证码、绑定一次完成，之后网页导入直达本机。

03 / Teach

开始上课

在课程或即时对话里选中这位导师。学习记录只留在你自己的电脑上。

学伴Card Market

登录市集账号

账号只用于卡片市集。学习数据、教材和对话不上传。

还没有账号？注册入口在学伴桌面端：打开「我的人物」→「上传到市集」→「绑定市集账号」，浏览器会打开注册页，完成邮箱验证后自动绑定本机。
