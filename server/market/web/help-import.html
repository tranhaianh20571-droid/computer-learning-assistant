How to import

把卡片
装进你的学伴。

卡片不是聊天提示词，而是一份完整的人物包：人物设定、教学方法、状态素材都在里面。导入后它会出现在你本机的「我的人物」，学习记录不会上传到市集。

为什么要在本地操作

市集只保存卡片本身。你的课程、教材、对话和记忆都在这台电脑上，所以导入动作必须由本机完成 —— 市集只能"把卡片交给你"，不能直接写进你的电脑。

按账号接收，按账号保存

市集 A 账号的卡片只进入 A 的本地空间。本机未登录或当前登录 B 都能后台接收，切换到 A 后即可查看；不会写进 B 的人物列表。

方式一：直接导入到本机（推荐）

  1. 先在电脑上打开学伴，保持运行。
  2. 第一次使用：在学伴登录页点击「仅开启市集接收」，或在网页离线提示中点「开启账号接收」，然后在市集登录需要接收的账号并确认授权。本机无需登录，也不会切换当前账号。
  3. 回到市集页面，打开任意卡片，点「导入到学伴」。
  4. 弹窗里点「直接导入到本机」，后台会接收并保存到该市集账号的本地空间。登录该账号后，在「我的人物」查看。

能直接导入

学伴服务正在运行，并且当前市集账号已开启本地接收。本机页面可以停留在登录页。

提示本地离线

请启动学伴，或为当前市集账号开启接收；如果此前暂停接收，请登录对应本机账号后恢复。启动后等待片刻再重试。

方式二：下载 ZIP 手动导入

  1. 在导入弹窗右下角点「下载 ZIP」。
  2. 打开学伴 →「我的人物」→「导入卡片」。
  3. 选择刚下载的 .studycard.zip 文件，支持一次选多个。

ZIP 里包含人物设定、对话方法和全部状态素材；不包含任何人的学习记录，也不包含语音服务凭据。

方式三：上传自己的卡到市集

  1. 在学伴里建好人物、补齐设定和状态素材。
  2. 「我的人物」→「上传到市集」，勾选要上传的卡片。
  3. 上传成功后会出现在市集；同一张卡重复上传会被识别为已存在。

常见问题

导入后在哪里找？
学伴左侧「人物导师」→「我的人物」，打开后即可选择该导师开始上课。

会覆盖我现有的卡吗？
不会。导入会用新 ID 创建一份可编辑副本，原有的卡和记忆不受影响。

换账号或换电脑了怎么办？
每个账号分别授权接收，互不混用；退出本机登录不停止接收。暂停或撤销可在对应账号的「上传到市集」窗口操作。换电脑时重新授权即可，学习记录需另行迁移备份。

下载会计入热度吗？
会。同一账号对同一张卡每天只计一次，用来生成近 3 天热门。
