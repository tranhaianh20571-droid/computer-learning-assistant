# 设置页设计简报

## 当前方向

用户已选定：与应用其它页面一致的中国水墨风，极简、黑白。当前交付为[水墨设置页](水墨.html)离线交互样稿，不修改正式应用。

- 视觉：中性灰白纸面、黑色主操作、细线分层、宋体标题，不使用彩色强调、渐变、光晕或卡片套卡片。
- 结构：桌面为左侧设置分类、中部配置列表、右侧配置详情；平板采用顶部分类导航，手机采用两列导航与纵向详情。
- 核心任务：比较已保存配置，添加、编辑、测试或删除指定配置。
- 演示：加载、取消、成功、失败、空态、授权查询、设备配对、图片样例放大均使用合成数据。

## 功能结构

1. 模型与语音：内容模型、封面图片、语音合成，列表和详情分离。
2. 本机连接器：设备状态、一次性演示配对码、撤销。
3. 外发授权：按任务查询、撤销演示授权。
4. 云端能力：管理员 OCR 与搜索；生产环境必须由权限控制。

## 设计约束

- 不新增默认模型切换逻辑；“后续任务使用”只表达既有的“同类使用最近新增配置”约定，选中项不等于生效项。
- 不保存凭据、不连接网络、不调用供应商、不改变正式页面或用户数据；刷新恢复初始状态。
- 图片、语音测试可能计费的正式边界保留；撤销授权不能收回已发送内容。
- 字体使用系统字体；图标来自 Lucide（MIT）；树形水墨 PNG 为项目合成样例。
- 黑白状态同时使用图形与文字，不能只靠颜色区分。
- 对话框使用原生 dialog，补充焦点循环、名称和关闭后焦点恢复。

## 历史方向

[校准台](校准台.html)、[声场](声场.html)、[书页](书页.html)保留作为前期探索。用户最终明确选择应用原有的中国水墨、极简黑白方向，因此不继续使用发现阶段的彩色方案。

种子、初稿评审、后续修整与验收见[设计记录](设计记录.md)。

## 交付边界

这是一套可独立打开的设计文件，不是正式设置页功能替换。接入正式应用时仍需对齐后端配置 API、管理员权限、凭据加密、MiniMax 音色目录及持久状态管理，不能以离线演示结果替代这些验收。
