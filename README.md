# 学习助手伙伴

<img src="desktop/assets/logo.png" alt="学习助手伙伴 Logo" width="96" height="96">

**把你的论文、教材和视频，变成一门有人陪你学完的课。**

读论文卡在公式，看视频越攒越多，问完 AI 却不知道下一步学什么？

学习助手伙伴把**你的资料、学习路线、语音课堂、动手练习和复习录像**放进同一个桌面学习空间。从一份资料或一个目标开始，和 AI 聊清楚基础与时间安排，再按自己的节奏学下去。

## 让正在读的资料，成为你的专属课程

上传论文、教材和讲义，或导入网页与视频，就能围绕这些内容组织学习。文档识别支持正文、公式、表格和图片，视频支持转写，把散落在不同地方的学习材料接到同一条课程线上。

**讲解有原文可对照。** 论文精读从开篇建立背景，随讲解定位段落和图示；遇到“如图一”，可以直接核对对应位置。原始、改编与 AI 生成内容保留来源区分，方便查证和深入阅读。

## 一边听、一边看，随时追问

语音、字幕、板书和原文组成一间可以互动的课堂。公式、图解和代码随讲解展开；哪里没懂就暂停追问，代码可以直接运行，费曼问答帮助你把理解说出来。

翻到前面的论文页查看背景后，角落里的返回图标带你回到当前讲解位置。左侧细进度条支持回看已经讲过的内容，让重听和继续学习都顺手。

## 学完就能回放，重点还能带走

**桌面课堂默认自动录制画面与课堂语音。** 无需操作录制按钮，完成学习后点“复习”，就能播放已保存的课堂录像，拖动进度条反复看难点。中途离开再回来，录像按片段保存；未完成保存的片段可以尝试恢复。

想快速整理笔记？导出当前板书 PNG，或把本讲已讲板书导出为 PDF，把公式、图解和代码一起留下。旧课程在启用录制前的内容不会自动补成录像，仍可查看已有知识点。

## 学什么、怎么学，由你决定

先讨论目标、基础、时间和范围，再生成学习路线。课程、单元和讲次通过导图连起来，可以直接调整，也可以和 AI 讨论后修改。确认后的版本保留下来，随后的讲解和练习有清晰的学习范围。

单元测验、订正与费曼表达帮助检验理解；已保存的课程进度和个人记忆，让下次学习接着往前走。你还可以设定学伴人物与讲解风格，让陪你学习的角色更合心意。

## 模型自由选，学习数据留在自己的电脑

课程规划、课堂讲解和即时对话可以分别选择模型，在效果、速度和成本之间灵活搭配。个人记忆也支持独立配置模型、Embedding 和重排服务。

桌面版自动准备 Python、数据库、转写和记忆运行组件。安装时选择目录，首次启动完成组件准备后，在设置里填写自己的 API Key，即可开始配置学习服务。课程、资料和录像保存在本机，凭据加密保存，卸载默认保留个人数据。

![个人记忆模型设置](assets/desktop-settings.png)

## 三步开始学习

1. 下载并安装 Windows 桌面版，首次启动保持联网，等待组件准备完成。
2. 在设置中连接自己的模型与所需学习服务。
3. 上传一份资料或描述学习目标，确认课程，进入课堂。

目前提供 **Windows x64 预览版**，安装包尚未配置发布者代码签名。外部模型、OCR、转写或搜索能力以实际配置为准，调用费用由相应供应商收取，本项目不附带 API 额度。调用外部服务时，相应内容会发送到你配置的供应商；本机存储不等于全程离线。自动视频录制与板书文件导出用于桌面版课堂，网页端仍可使用讲解与知识点复习。
