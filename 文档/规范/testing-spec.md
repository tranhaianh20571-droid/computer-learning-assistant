# 通用测试与验收归档规范

## 1. 目标与边界

本规范约定软件项目中**可执行测试**与**验收证据归档**的组织方式，适用于任何采用"单一测试真源 + 证据归档"模式的项目。规范目录只放规则；带日期的执行证据一律放独立的归档目录，两者不混层。

## 2. 测试真源与目录约定

- 仓库应只有**一个**可执行测试入口目录；其他位置的测试目录属于遗留时必须清理或明确标注不可执行。
- 测试按主题前缀命名（专项地基、业务切片、架构版本、集成），保持平铺；不为分组创建子目录，除非文件数量明显超出检索效率（建议阈值 80 个）。
- 共享夹具放测试根的公共模块，命名体现用途而非首次出现的切片；夹具必须全部合成，不得包含真实凭据、真实用户数据、生产 URL 或完整生产日志。
- `conftest.py` 承担公共路径装配与环境默认值；单个测试文件不再重复路径样板。
- 若存在"生产代码镜像树"（测试导入镜像而非生产包），镜像与生产必须**逐字节一致**，允许的例外（垫片、测试专用夹具文件）以显式清单登记，并由自动化校验测试守护：镜像中每个非例外文件必须与生产对应文件哈希相等。

## 3. 运行与数据库

- 测试命令、依赖环境、数据库准备步骤在测试真源目录的 README 声明，且是唯一权威说明。
- 需要数据库的测试应支持通过环境变量指向测试库；测试库结构与迁移一致性由迁移工具维护，测试不得静默绕过。
- 未实际运行的命令与检查一律标记"待执行"；写完代码不等于通过。

### 3.1 回归范围选择

回归按改动的影响范围与风险选择，不要求每新增一个功能都执行全量。开始验证前，检查改动模块的调用方、共享依赖、下游流程与数据契约；同次交付存在多项改动时，按合并后的影响范围选择，不能分别缩小范围后遗漏模块间交互。

| 改动或交付场景 | 必须覆盖的验证 |
| --- | --- |
| 纯文档、注释调整，且未改变接口、权限或验收契约 | 差异、链接、引用与规则一致性等静态检查；不要求运行应用全量回归 |
| 局部 UI、文案或独立业务功能 | 新增或变更行为的专项验证，加受影响模块的既有回归；涉及交互时验证相关浏览器行为 |
| 跨模块业务流程，如规划确认影响课程创建 | 相关模块回归，加从入口到结果持久化的完整业务链路验证 |
| 共享基础能力变更，如登录权限、数据库结构或迁移、公共模型适配器、公共任务状态与租约、共享日志与审计机制 | 全量自动化回归，加对应的权限隔离、迁移、故障恢复等专项验证 |
| 阶段验收或发布前 | 对待验收或待发布版本执行全量自动化回归，加关键用户流程与本次变更对应的专项验证 |

影响范围无法可靠确定、专项失败暴露出跨模块问题时，必须重新评估并扩大回归，必要时执行全量。文档调整若改变接口、权限或验收契约，也须评估实现是否受影响，按表中对应场景验证；文档静态检查不能证明实现满足新契约。

“全量自动化回归”指测试真源 README 中声明的完整自动化套件。浏览器流程和真实供应商验证若需单独执行，必须分别记录范围与结果，不能被套件通过数代替。使用合成适配器、前端隐藏控件或构建成功，均不能证明真实供应商可用或服务端权限隔离有效。修改生产代码镜像涉及的文件时，专项回归也必须包含镜像同步校验。

每次执行记录须写明改动与影响范围、选择该范围的理由、实际命令与结果，以及未验证项和原因。专项通过不得标记为全量通过；全量有失败、跳过或未执行项时必须逐项如实记录，不得把它们计为通过。本次仅运行专项时，不更新“最近全量回归”的日期和通过数；新增或变更测试仍须同步维护测试索引与当前用例基线。

## 4. 证据归档约定

- 归档目录与规范目录分离；内部按"专项/切片"分目录，同层级不搞历史特例。
- 每次验收归档至少包含：执行记录（运行目录、依赖与工具版本、命令、结果、证据路径）与结论（通过/失败/待执行），失败项保留原因。
- 样例日志、脱敏记录等证据文件必须是合成数据或已脱敏的生产形态样例，禁止完整生产日志入库。
- 代码中的契约注册表（事件、字段、错误码等）如有机器可读导出，归档中保存**版本化快照**；新快照不覆盖旧快照，权威以代码为准。

## 5. 索引与时效

- 归档 README 维护"阶段 ↔ 记录 ↔ 测试"索引表，新增测试层或基线变化时同步更新；追加式更新允许，但主表必须反映当前基线（用例数、通过数）。
- 历史运行环境记录标注"历史"并指向当前权威说明；文档改名时同步更新全部引用。

## 6. 实施检查清单

1. 测试真源唯一且 README 准确；无重复路径样板；镜像校验测试在位且通过。
   回归范围按第 3.1 节选择，记录影响范围、选择理由和未验证项；专项结果与最近全量结果分开维护。
2. 归档与规范分层清晰；索引表与当前基线一致。
3. 夹具全合成；扫描无凭据、无生产正文。
4. 删除遗留测试目录时，先确认引用为零再删，并在归档记录。
