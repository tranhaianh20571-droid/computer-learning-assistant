# 学习助手伙伴

<img src="desktop/assets/logo.png" alt="学习助手伙伴 Logo" width="96" height="96">

**围绕你的资料、目标和理解进度，把学习持续下去。**

学习助手伙伴是一款 AI 学习桌面应用。把论文、教材、网页或视频交给它，从讨论学习目标、制定课程，到课堂讲解、动手练习、检验理解和复习，在同一个学习空间里完成。

[下载 Windows 桌面版](https://github.com/tranhaianh20571-droid/computer-learning-assistant/releases) · [反馈问题与建议](https://github.com/tranhaianh20571-droid/computer-learning-assistant/issues)

## 从自己的资料开始

学习可以从一份正在读的论文、一门课的讲义，或者一个想解决的问题开始。支持文件、网页和视频导入；文档通过 OCR 保留正文、公式、表格和图片，视频可以转写为后续学习的资料。

讲解与练习可以关联原始资料，在课堂里回看原文和出处。原始内容、改编内容和 AI 生成内容保持区分，方便核对，也方便继续深入阅读。

## 先聊清楚，再决定怎么学

通过对话明确目标、已有基础、时间安排和学习范围，再生成课程路线。导图把课程、单元和讲次连起来，让学习顺序看得见。

规划完成后，你可以直接调整导图，也可以与 AI 交流修改讲解结构。确认后的课程会保留为稳定版本，后续学习有一份共同参照。

![学习空间](assets/desktop-home.png)

## 把“看过”推进到“理解”

课堂把板书讲解、原文阅读、随堂追问、代码运行与语音放在一起。遇到不明白的地方可以暂停、追问，再回到当前学习进度。

学完之后，通过单元测验、订正和费曼表达检查理解，再进入课程复习。课程进度与个人记忆让下一次学习能够延续之前的上下文。

| 你正在做的事 | 学伴提供的支持 |
| --- | --- |
| 读一份陌生资料 | 导入与识别、原文定位、按资料展开讲解 |
| 想学一个主题，却不知道从哪开始 | 对话了解需求、规划路线、导图确认与调整 |
| 听懂了，却还不会用 | 课堂问答、代码运行、练习与反馈 |
| 想确认自己到底理解了多少 | 单元测验、订正、费曼表达 |
| 隔一段时间继续学习 | 已保存的课程进度、复习与个人记忆 |

## 选择适合自己的 AI

课程规划、课程讲解和即时对话可以分别选择模型，按任务需要平衡效果、速度和成本。API Key 在设置里填写，个人配置加密保存。

支持人物设定与学伴角色，也支持单独配置个人记忆使用的模型、Embedding 与重排服务。学习资料、课程和记忆按用户隔离。

## 桌面学习空间

Windows 桌面版自动准备独立的 Python、数据库、视频转写和个人记忆运行组件，减少环境配置。课程和资料保存在本机的数据目录，卸载默认保留个人数据。

市集支持选择电脑上已安装的浏览器，也可以选择便携版浏览器。日常学习界面直接在应用内打开。

首次准备组件需要联网。使用外部模型、OCR 或搜索时，相应内容会发送到你配置的服务，能力与费用取决于供应商；本项目不提供 API 额度。桌面版目前为 Windows x64 预览版，安装包尚未配置发布者代码签名。

前端使用 React 与 TypeScript，后端使用 FastAPI，桌面壳使用 Electron。欢迎通过 Issues 反馈学习过程中的问题或提出建议。
