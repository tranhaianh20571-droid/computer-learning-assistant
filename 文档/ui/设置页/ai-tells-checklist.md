# 水墨设置页减法检查表

本表对应[水墨样稿](水墨.html)，不是正式应用上线证明。评审门 G2 未达到，详见[设计记录](设计记录.md)。

| 检查项 | 处置 | 理由 |
| --- | --- | --- |
| 左文右图英雄区与营销 CTA | 已处理 | 首屏直接配置操作，没有营销英雄区 |
| 三列特性卡片 | 已处理 | 使用能力页签、配置列表和详情 |
| 所有分区等宽居中 | 已处理 | 桌面按导航、列表、详情任务分工 |
| 卡片套卡片 | 已处理 | 分隔线、间距和字重建立层级 |
| 紫色渐变背景 | 已处理 | 中性纸白与黑灰，无彩色渐变 |
| 光晕、霓虹描边 | 已处理 | 无此装饰 |
| 随机彩色文字 | 已处理 | 状态同时用图形和文字 |
| 多强调色竞争 | 已处理 | 黑色主操作，不引入彩色强调 |
| 过度解释 | 有意保留必要边界 | 凭据、演示、计费、撤销边界是安全事实；其余说明降级 |
| 夸奖和安慰文案 | 已处理 | 只显示操作结果和下一步 |
| 营销空话 | 已处理 | 没有营销承诺 |
| 重复隐喻 | 已处理 | 不用隐喻解释配置 |
| emoji 与密集加粗 | 已处理 | 图标为 Lucide，字重用于层级 |
| 字号层级失衡 | 已处理 | 操作正文 14px，状态和协议辅助信息 13px，标题单独层级；沿用设置工具密度 |
| 自造控件劣于原生 | 已处理 | 原生表单、select、progress、dialog |
| 胶囊徽章泛滥 | 已处理 | 状态为轻量文字/图形，使用项下划线 |
| 每个按钮都有图标 | 有意保留工具符号 | 编辑、删除、刷新等用熟悉符号；保存、取消、查询结果不靠装饰 |
| 几何图形替代主视觉 | 已处理 | 无装饰主视觉，封面类别展示真实 PNG 样例 |
| 3D blob 与毛玻璃 | 已处理 | 不使用 |
| 素材风格不一 | 已处理 | 只用一张灰度水墨树图 |
| 所有元素淡入上移 | 已处理 | 无页面入场编排 |
| 悬停放大、无限旋转 | 已处理 | 无此装饰；减少动效偏好可关闭过渡 |
| 冗余标签与空白 | 已收紧，仍有残余 | 删除编号/英文副标题；桌面短列表留白仍是评审中的已知不足，不宣称消失 |
| 重复标题与副标题 | 有意保留定位信息 | 当前分类标题与所选配置名提供不同定位；未再增添宣传副标题 |
| 只有成功路径 | 已处理 | 加载、空、错误、成功及恢复检查覆盖 |
| 长任务无进度取消 | 已处理 | 合成测试含阶段、计时、进度与取消 |
| 焦点不可见、div 冒充按钮 | 已处理 | 语义化 button、可见焦点、弹窗 Tab 循环与关闭焦点恢复 |

响应式与交互证据：[16 项交互检查](screens/ink-checks.json)、[可访问性采样](screens/ink-accessibility.json)。检查不替代真实设备、屏幕阅读器或后端授权验收。
